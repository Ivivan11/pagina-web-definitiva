# Videojuego

Proyecto nuevo, arrancando desde cero. Base mínima con HTML5 Canvas y JavaScript vanilla: un cuadrado que se mueve con las flechas o WASD.

## Cómo ejecutarlo

Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático.

## Estructura

- `index.html` — punto de entrada
- `style.css` — estilos
- `script.js` — lógica del juego
